# quant-demos

Teaching and demo material explaining quant trading concepts. Each demo is a standalone HTML file — open it in a browser.

- [l2-vs-l3-order-book.html](l2-vs-l3-order-book.html) — L2 (aggregated price levels) vs L3 (individual orders) order book data
- [pov-order-simulator.html](pov-order-simulator.html) — percent-of-volume (POV) execution simulator
